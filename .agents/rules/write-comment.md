Always write an English docstring for every Python function that is added or modified.

All comments and annotations in source code must be written in English.

Tensor and variable shapes: proactively annotate the output shapes of key tensors and variables in comments, for example `# [B, 1024, 3]` or `# Shape: list of length B of tensors with shape [N, 3]`.
